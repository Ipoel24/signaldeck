# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in SignalDeck, please report it responsibly.

**Do not** open a public GitHub issue for security vulnerabilities.

Instead:

1. Email the maintainers (or use GitHub's private vulnerability reporting if enabled).
2. Provide a clear description of the issue, steps to reproduce, and potential impact.
3. Allow reasonable time for a response and fix before any public disclosure.

We will acknowledge receipt of your report as quickly as possible and keep you informed of the progress toward a fix.

Thank you for helping keep SignalDeck and its users safe.
